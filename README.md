# Get Started

## Get LLM´s

0. download ollama
1. Get modoel nomic-embed-text: ollama pull nomic-embed-text
2. Get model llama3: ollama pull llama3 




## Installation der Abhängigkeiten

1. Virtuelle Umgebung erstellen (optional, empfohlen):

```bash
python -m venv venv
```

2. Aktivieren

- macOS / Linux
```bash
source venv/bin/activate
```

- Windows
```bash
venv\Scripts\activate
```

3. Pakete Installieren:
```bash
pip install -r requirements.txt
```
